SKILL ROUTING
=============

- Planning: openspec-explore for uncertain requirements;
  openspec-propose for each feature; openspec-update-change when an
  existing feature plan must be reconciled.
- Implementation: openspec-apply-change is the driver. Use
  architecture-standards and karpathy-guidelines for substantive code,
  vercel-react-best-practices for React, and pwa-expert for offline,
  worker, service-worker, and cache work.
- Visual work: always use antislop core plus antislop-ui. Add
  antislop-human and antislop-layoutmobile for interface and phone work;
  use antislop-copywriting when writing user-facing copy. Apply these
  during implementation and again at delivery.
- Verification and closure: openspec-verify-change, the antislop
  delivery gate, then openspec-archive-change.
- Commit message: caveman-commit. The skill writes the message; the Git
  commands above stage, commit, and push.
- For a difficult bug, use diagnosing-bugs before returning to apply.
